📊 Inclusion–Exclusion

The Inclusion–Exclusion Principle is explained for counting distinct elements in the union of sets while accounting for overlapping elements.

For two sets:

|A ∪ B| = |A| + |B| − |A ∩ B|

A computing-oriented example involving students who know Python and Java is also included.

🔗 Partially Ordered Sets

The assignment introduces Partially Ordered Sets (Posets) and explains the three properties of a partial order:

- Reflexive
- Antisymmetric
- Transitive

A divisibility relation is used as an example of a Poset.

📈 Hasse Diagrams

Hasse diagrams are used to visually represent finite Posets. The assignment includes examples based on:

- Divisibility
- Subset relations
